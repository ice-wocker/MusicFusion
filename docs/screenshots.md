2. **Library** (albums / artists / tracks tabs)
3. **Search** (with source filter)
4. **Equalizer** (10-band with custom curve)
5. **Download manager** (with progress)
6. **Podcast** (subscriptions + playback)
7. **Listen stats** (weekly chart)
8. **Theme picker** (AMOLED, light, custom)
9. **Settings** (with Last.fm, MusicBrainz, download)
10. **Widget** (2x1 / 4x1 / 4x2)

## How to Contribute Screenshots

If you have the app installed and want to help:

1. Take a screenshot (any tool - scrcpy, adb, phone)
2. Optimize to <500KB with `pngquant` or `cwebp`
3. PR to add to this directory with descriptive alt text

The current README references these via placeholder image links:
```html
<img src="docs/screenshots/now-playing.png" alt="Now Playing" width="200">
```

When real images arrive, they'll be:
- Saved as WebP for size
- Lazy-loaded for performance
- Have descriptive alt text for accessibility
